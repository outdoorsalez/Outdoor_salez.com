# 🎣 Outdoors Salez

**Outdoors Salez** is a simple e-commerce website for selling **recycled soft plastic fishing lures**.

Our goal: **Catch fish while reducing plastic waste.**

---

## 🌊 About

We create fishing lures from recycled soft plastics to help keep lakes and rivers clean.  
This site is designed to showcase products and allow customers to purchase them easily online.

---

## 💰 Pricing

- **1 Lure — $2**
- **3 Lures — $5**

---

## 🛒 Features

- Clean outdoor/fishing-themed design  
- Product image gallery  
- Secure checkout using Stripe  
- Instagram integration for orders and promotion  
- Mobile-friendly layout  

---

## 🚀 How to Use

1. Open the website  
2. Browse available lures  
3. Click **Buy Now**  
4. Complete payment through Stripe  
5. Receive confirmation and order details
